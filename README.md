# 📻 WV Radio — بی‌سیم رادیو

یک پخش‌کننده‌ی رادیوی اینترنتی با ظاهر واقعی یک دستگاه بی‌سیم قدیمی (walkie-talkie) — آنتن، سیم‌های جریان‌دار، صفحه‌ی LCD سبزفسفری و دکمه‌های فیزیکی. همه‌چیز فقط با **HTML + CSS + JavaScript خالص**، بدون هیچ فریم‌ورک یا وابستگی بیرونی، در یک فایل واحد.

> A single-file, dependency-free HTML radio player styled like a real handheld walkie-talkie — antenna, glowing signal wires, a phosphor-green LCD screen, and physical-feeling buttons. Built with vanilla HTML/CSS/JS.

---

## ✨ امکانات

- **۲۲ رادیوی اینترنتی واقعی از پیش نصب‌شده** در سه دسته: اخبار آمریکا، موسیقی کانتری/کابویی (تگزاس)، و موسیقی متنوع آمریکایی (جاز، ایندی، فولک و...)
- **پخش / توقف، رادیوی بعدی و قبلی، کم و زیاد کردن صدا** — همه با دکمه‌های واقعاً فعال
- **افزودن رادیوی دلخواه** با وارد کردن لینک استریم — رادیوهای شخصی قابل حذف‌اند، رادیوهای پیش‌فرض قفل 🔒 هستن و حذف نمی‌شن
- **جست‌وجوی زنده** داخل لیست رادیوها
- **اکولایزر تصویری** که هنگام پخش با ریتم‌های نامنظم حرکت می‌کنه
- **۴ تم رنگی برای بدنه‌ی دستگاه**: تیره‌ی کلاسیک، طلایی، نظامی، سفید کلاسیک
- **سیم‌ها و آنتن انیمیشنی**: هنگام پخش، یه موج نورانی سبز واقعاً توی سیم‌های کناری و سیم آنتن جریان پیدا می‌کنه
- **قابل نصب روی صفحه‌ی اصلی گوشی (PWA)** — بعد از هاست کردن، مثل یه اپ واقعی نصب و باز میشه
- **ذخیره‌سازی کامل در مرورگر (localStorage)**: رادیوهای شخصی، صدا، آخرین رادیو، و تم انتخابی بین بازدیدها حفظ می‌مونه
- بدون بک‌اند، بدون build process، بدون npm — فقط یک فایل `radio.html` که مستقیم توی مرورگر باز میشه

## 🚀 اجرا

### روش ۱ — مستقیم
فایل `radio.html` رو دانلود کن و توی هر مرورگری بازش کن. همین!

### روش ۲ — هاست روی GitHub Pages (پیشنهادی)
برای فعال شدن کامل قابلیت نصب روی گوشی (PWA):

1. این ریپو رو فورک/کلون کن
2. از تنظیمات ریپو، **Settings → Pages** رو باز کن و شاخه‌ی مربوطه رو به‌عنوان source انتخاب کن
3. آدرس داده‌شده رو باز کن — روی گوشی اندروید دکمه‌ی «نصب اپ» ظاهر میشه و روی آیفون از Safari → Share → Add to Home Screen قابل نصبه

## 🛠 ساختار فنی

- تک‌فایلی: `radio.html` شامل CSS و JS به‌صورت inline
- عنصر `<audio>` بومی مرورگر برای پخش استریم‌ها
- ذخیره‌سازی با `localStorage` (بدون نیاز به سرور یا دیتابیس)
- مانیفست PWA و آیکون به‌صورت `data URI` داخل همون فایل تعبیه شده (نیازی به فایل جدا نیست)
- فونت فارسی [Vazirmatn](https://github.com/rastikerdar/vazirmatn) و فونت دیجیتال Share Tech Mono از گوگل فونت

## ➕ افزودن رادیوی خودت

از دکمه‌ی «＋ افزودن»، یک اسم و یک **لینک مستقیم استریم** (نه لینک صفحه‌ی وب‌سایت رادیو) وارد کن. لینک باید مستقیماً به یک فایل صوتی یا استریم icecast/shoutcast ختم بشه، مثلاً چیزی شبیه:

```
https://example.com/stream.mp3
```
